# NEXUS — Automotive Intelligence

LEXUSのAI体験と、販売店のバリューチェーンをつなぐプレゼンテーション用コンセプトです。
すべての数値・会話・店舗・施策はサンプルです。実際のAI、予約、販売店システムとは接続していません。

## プレゼンで使う

1. `index.html` をブラウザで開くか、公開ページへアクセスします。
2. 右上の全画面ボタンを押します。
3. 「プレゼンを開始」で、5つのシーンを約60秒で自動再生します。
4. 途中で一時停止すると、スライダーやKPIを自由に操作できます。

`?present=1` をURLに付けると、入場演出の後にツアーが始まります。

- **Overview**：動くネットワーク、成長の推移、4つの主要指標。
- **AI Experience**：RX / NX / RZの選択、4つのAIの切替、会話から来店につながるシナリオ。
- **Value Chain**：タイヤ購入率・作業枠稼働・固定費・年次のシミュレーション。
- **21 Core KPIs**：GS 5 / BP 6 / 保険 6 / 用品 1 / 固定費 3。フィルターと詳細パネル。
- **Action Studio**：KPIやシナリオをアクションに追加。着手・完了をブラウザに保存。

キーボード：1〜5で画面切替、ツアー中のSpaceで一時停止、左右矢印でシーン切替、Escで詳細・ツアー終了。
モーション切替に対応。OSの「動きを減らす」設定も尊重します。

## ファイル

`index.html`、`assets/styles.css`、`assets/app.js`、`assets/chart.umd.js`、`assets/vision.webp`を同じ構成で配置してください。
外部CDNやデータAPIに依存せず、画像・グラフ描画ライブラリを同梱しています。

- サンプルKPIとアクション：`assets/app.js` 内の `BASE_KPIS` / `initialActions`。
- 簡易シミュレーション：`projectedRatio`。予測モデルではなく演出用の計算です。
- 操作保存キー：`nexus-concept-actions-v1`。画面内の「デモの状態に戻す」で初期化できます。
- キービジュアル：このコンセプト用のAI生成画像。実在車種の写真ではありません。
