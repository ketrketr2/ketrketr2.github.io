# NEXUS — TMT Dealer Intelligence

タイ・トヨタ販売店のVC収益と21コアKPIを扱う、プレゼンテーション用ダッシュボードです。黒とシャンパンゴールドのデザイン、コンセプトカーの画像、動くネットワークを維持し、内容を販売店オペレーションに統一しています。

## 6つの画面

1. **Monday Cockpit**：店長メッセージ、VC吸収率・サービス売上・粗利率・未対応アクション、5領域の状況、アラート、タイヤファネル、同規模店比較、朝礼の4項目。
2. **21 Core KPIs**：GS 5 / BP 6 / 保険 6 / 用品 1 / 固定費 3。実績、実数、改善余地、類似店、13週、本部、前年差、データ準備状況。コンパクト・詳細表示を切替。
3. **Growth Drivers**：タイヤ・バッテリー・エアケアのファネルと試算、WB稼働率、BPのT.CARE構成と値引き、コアからプロセスへの段階的な深掘り。
4. **Dealer Network**：154件の架空ディーラー。地域・規模・並び順・ページを切替。WB稼働率とVC吸収率の散布図、店舗詳細。
5. **VC Roadmap**：PDFの70 → 72 → 81 → 約90%の道筋、85%の基準達成ケース、改善レバーのシミュレーション、Phase 1 / Phase 2。
6. **Action Studio**：朝礼で決める担当・期限・アクション。KPIや改善試算から追加して、着手・完了を記録。

## プレゼン

`index.html`をブラウザで開き、右上で全画面表示にして「プレゼンを開始」。6画面を約60秒で巡ります。
URL末尾に `?present=1` を付けると、入場演出の後に自動再生します。
1〜6で画面切替、ツアー中はSpaceで再生・一時停止、左右矢印で前後へ、Escで詳細・ツアー終了。
動きを減らす設定にも対応します。

## 参考資料とデモ設定

- **VC資料.pdf**：VC吸収率の段階計画、GS・BPの基準、WBの機会、T.CARE・値引き、Phase 1 / 2、プロセスツリー。
- **21コアKPIマトリクス サンプル.html**：21 KPIの名称、値、実数、改善余地、類似店・13週・本部の比較。
- **Monday Store Manager Dashboard.html**：月曜朝の全体構成、店長の重点、タイヤの点検420→交換必要82→見積54→成約18、朝礼の4項目。
- **TMT VCキックオフ文書**：21 KPIの定着を優先、タイヤ・バッテリーを重点化、データ取得の3分類、店舗比較と運用。

店舗名・154件の比較データ・時系列・期間切替・前年差・補完する商品別ファネル・シミュレーションはデモです。
通貨はタイ向けにTHBへ置き換えたサンプルで、円からの為替換算ではありません。MBは百万バーツ。
データ取得分類の個別割付、Minimum / Criterion / Idealの詳細閾値もデモ設定。PDFにある参考基準は別記しています。
HTMLの現行比較値とPDFの到達基準は混同せず併記しています。カード件数は表示データから算出します。
PDFの2030年の本文89% / 図表90%は「約90%」として整理しました。
原本や社内打ち合わせ記録は公開ファイルに含めていません。

## 動作と保存

画像、Chart.js、データを同梱し、外部CDNやデータAPIなしで動きます。
アクションはこのブラウザの店舗別に保存します。通知や実システムへの送信はありません。
保存キーは `nexus-tmt-actions-v2`。旧版の保存状態は引き継ぎません。

`assets/data.js`にKPI、実数、比較値、取得状況と初期アクション、`assets/app.js`に表示と操作があります。
コンセプトカーはAI生成画像で、実在車種の写真ではありません。Chart.js 4.5.1のMIT表記を保持しています。
