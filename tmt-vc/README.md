# TMT VC COMMAND

An English-language presentation dashboard for Toyota Thailand dealer value-chain operations. Uses the agreed 21 core KPIs and the supplied VC driver/process structure. All dealers, time series and scenario outputs are demonstration data.

## Explore

1. Monday Cockpit — dealer results, priority alerts, quotation funnel and briefing.
2. 21 Core KPIs — GS 5 / BP 6 / INS 6 / ACC 1 / COST 3; evidence, references, editable sample inputs and CSV export.
3. KPI Explorer — collapsible core map and GS process tree, search, zoom, pan, branch selection and linked actions.
4. Opportunity Lab — tire, battery, air care, workbay and T.CARE scenarios; save / compare / restore A and B per dealer.
5. Dealer Network — 154 synthetic records, region and scale filters, scatter selection and two-dealer comparison.
6. VC Roadmap — source milestones, contribution structure and interactive illustrative sensitivity model.
7. Action Studio — create and edit commitments, owners and dates; drag between statuses or use buttons; export CSV.

## Source adoption

- The supplied 21 Core KPI Matrix HTML provides all 21 labels, values, actuals, improvement gaps and comparison references. BP Bill C is displayed in thousands of THB per job, consistent with the supplied THB 9.6M / 100-job example.
- The Monday Store Manager HTML provides the briefing structure and tire funnel: 420 inspections → 82 replacement needs → 54 quotations → 18 sales.
- VC PDF p.1 / p.6: 70% baseline, 72% end-2026, 81% 2027, approximately 90% 2030; the independent all-dealer criterion case is 85% excluding cost reduction. The source's 89% heading and 90% diagram are represented as approximately 90%.
- VC PDF p.2 / p.3: GS and BP guidelines, tire / battery / air care, revenue per head, T.CARE mix and discount structure.
- VC PDF p.7–8: UIO / CPUS / CRT by age band, Periodic Maintenance, Other appointment / walk-in, TCFR+, Smart Plan 3 / 5 / 10, PM Appointment, Call out / Call in / Online, Eco Pack, Additional Jobs and Tire Penetration. The visible branches are reproduced as an expandable tree. The tire quotation stages are linked from the HTML. No missing clipped PDF branch is invented.
- The kickoff document informs the emphasis on core KPI adoption, tire / battery drivers, data readiness and dealer operating routines.

The PDF and HTML have different references in places. Both are identified separately; for example BP workbay utilization has an 80% HTML reference and a 100% PDF Criterion. Supplementary level thresholds, data source-class assignments and process-node values are explicitly sample settings. Scenario equations are displayed in the relevant view.

## Presentation and offline use

Open index.html in a browser. All assets are local. Use full screen and Start presentation for a seven-scene, approximately 60-second tour. Keys 1–7 switch view; Space pauses the tour; arrow keys step; Escape closes details or ends the tour. Reduced motion is supported. The presentation includes an animated vehicle light sweep, floating particle field, cinematic transitions, flowing tree connections and scenario-result glow. The motion control pauses decorative movement.

Inputs, saved lab scenarios and actions are stored in the browser by dealer. KPI edits are also scoped to reporting week. The site sends no messages and has no live system connection. Storage key: tmt-vc-command-en-v3.

The concept vehicle image is retained from the earlier design and is AI-generated. Chart.js 4.5.1 is bundled with its MIT license notice. Original internal documents are not published.
